This project is a Movie Recommender System built using Python, Machine Learning, and Streamlit.
It recommends movies similar to the movie selected by the user and also displays movie posters using the OMDb API.

The recommendation system is based on content-based filtering using movie metadata such as genres, keywords, cast, crew, and overview.

Features
Recommend 5 similar movies
Interactive web interface using Streamlit
Movie poster fetching using OMDb API
Fast recommendation using cosine similarity
Clean and simple UI

How It Works
User selects a movie from the dropdown.
The system calculates similarity scores using cosine similarity.
Top 5 similar movies are selected.
Posters are fetched using the OMDb API.
Recommendations are displayed on the Streamlit interface.

Dataset

Dataset used:

TMDB 5000 Movies Dataset
TMDB 5000 Credits Dataset
